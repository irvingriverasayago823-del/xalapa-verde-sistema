# Xalapa Verde: Plataforma Comunitaria por el Clima

Prototipo funcional desarrollado como parte de la asignatura de **Ingeniería de Software**

## Descripción del Proyecto
Plataforma web diseñada para el cálculo de huella de carbono mensual en CO₂e a partir de parámetros municipales (energía, agua, transporte y residuos), además de la gestión e inscripción a campañas comunitarias, reforestación de plantones y generación de reportes estadísticos.

## Estructura del Repositorio
- `index.html`: Vista principal e interfaz de usuario integrada.
- `css/styles.css`: Estilos visuales institucionales basados en la paleta verde.
- `js/app.js`: Control de navegación y lógica de vistas de usuario.

## Tecnologías Utilizadas
- HTML5 / CSS3 / JavaScript
- Control de versiones con Git y GitHub
