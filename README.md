# Xalapa Verde: Plataforma Comunitaria por el Clima

Prototipo funcional desarrollado como parte de la asignatura de **Ingeniería de Software**[span_0](start_span)[span_0](end_span). 

## Descripción del Proyecto
Plataforma web diseñada para el cálculo de huella de carbono mensual en CO₂e a partir de parámetros municipales (energía, agua, transporte y residuos), además de la gestión e inscripción a campañas comunitarias, reforestación de plantones y generación de reportes estadísticos[span_1](start_span)[span_1](end_span)[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span)[span_7](start_span)[span_7](end_span).

## Estructura del Repositorio
- `index.html`: Vista principal e interfaz de usuario integrada.
- `css/styles.css`: Estilos visuales institucionales basados en la paleta verde.
- `js/app.js`: Control de navegación y lógica de vistas de usuario.

## Tecnologías Utilizadas
- HTML5 / CSS3 / JavaScript
- Control de versiones con Git y GitHub
